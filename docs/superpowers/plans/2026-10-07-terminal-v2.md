# Terminal v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner's clips flow in from an iCloud Drive folder, the terminal is reorganised into Today / Clips / Videos / Characters / More, and every character's master carries his own caption style and hook edit.

**Architecture:** A: a pure `studio/clipfolder.py` plus a `drop sync-folder` command run by a user LaunchAgent. B: the React terminal keeps every existing component and look; new pure helpers (`clipstatus.ts`, `dashboard.ts`, `videos.ts`) feed three rebuilt pages, routes are renamed with a legacy redirect. C: a `style` block in `characters/<slug>/refs.json`, read by `build_master`, drives `pill_png`, entrance overlays, hook-edit and tone filters.

**Tech Stack:** Python 3.12 (uv, typer, PIL, ffmpeg 8 without drawtext), React + TypeScript + Vite + vitest, macOS launchd.

**Spec:** `docs/superpowers/specs/2026-10-07-terminal-v2-design.md` (owner-approved 2026-10-07). Read it first.

## Global Constraints
- All state through `bin/studio` (CLAUDE.md); Supabase schema `studio` only; no new tables or migrations in this plan.
- No secrets in files; media never in git (fonts in `assets/fonts/` are allowed, with their OFL licence file).
- Commits: GitHub no-reply email; every message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never stage `.claude/settings.json` (unrelated local change).
- Never touch the uploaded master or posts of a queued, approved or scheduled clip (clip `06eb86e9` posts tonight 19:30 London). Style proofs render to `renders/tmp/` only.
- Nothing calls Higgsfield or spends credits in this plan.
- Masters: 1080x1920, 30 fps, 6-16 s, -14 LUFS ±1, true peak <= -1; end on the dance; the two ODD EYES dots `#8FD3FF` / `#FFB040` in every pill; no added audio (silence is not audio).
- Terminal look unchanged: reuse existing classes and components (`Section`, `.panel`, `.ll-table`, `.chips`, `.seg`, `.btn`, `.tag`); no restyle.
- Python tests: run the touched test files (`uv run pytest -q tests/<file>.py`, read the real exit code, never pipe through head/tail). The full suite takes ~75 min: the final task runs it file by file. Terminal: `cd terminal && npm test && npm run build`.

## Review Focus
1. An iCloud placeholder (`.<name>.icloud`) or a half-copied file must never be uploaded; the same clip copied twice must make one drop.
2. A file that fails validation (size, type) must never leave an orphan `uploading` pick: validate before `add_drop`.
3. Old bookmarks (`#/works`, `#/queue/<id>`, `#/library/<id>`, `#/picks?c=…`, `#/budget`) must land on the right new page with their parameter.
4. Reginald's pause adds 0.4 s at the start: every overlay window, enhancement `at_s` and the audio must shift by it, and the drop window must leave room so the master stays <= 16 s.
5. A character without a `style` block must master exactly as today (byte-for-byte filter graph): no regression for existing clips.

**Interfaces:**
- Consumes: `studio.drop.add_drop`, `attach_file`, `CLIP_EXTENSIONS`, `CLIP_MAX_BYTES`, `DropError`; `studio.storage.StorageError`.
- Produces:
  - `DEFAULT_FOLDER = Path.home() / "Library/Mobile Documents/com~apple~CloudDocs/ODD EYES clips"`, `ADDED_DIR = "Added"`
  - `DEFAULT_LEDGER = Path.home() / ".local/state/odd-eyes/clips-ledger.json"`, `SETTLE_SECONDS = 30`
  - `def scan_folder(folder: Path, now: float, fetch: Callable[[Path], None]) -> tuple[list[Path], list[dict]]` — ready files, and skipped `{"file", "reason"}` (reasons: `"in iCloud, downloading"`, `"still copying"`, `"not a video"`, `"over 200 MB"`).

Rules (from the spec): only top-level files of `folder` (never `Added/`); a placeholder is a file named `.<name>.icloud` → `fetch(folder/<name>)`, skip; a file whose mtime is within `SETTLE_SECONDS` of `now` → skip; extension and size checked BEFORE `add_drop(store, None, None, now)`; a hash already in the ledger → move to `Added/`, skip `"already added"`; after a successful `attach_file`, record `{hash: {"pick_id", "name", "at"}}` (ledger written atomically: temp file + rename, parent dirs created) and move the file to `Added/` (a name clash gets ` (2)`, ` (3)` …). A `DropError` / `StorageError` / `OSError` on one file goes to `failed` and the file stays; the others carry on.

### Task C2: entrances, hook edits, tones and the pause

**Files:** Modify `studio/media/master.py`, `studio/media/overlays.py`, `studio/media/analyze.py`; Tests `tests/test_master.py`, `tests/test_analyze.py`.

**Interfaces:**
